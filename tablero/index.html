03 / Protocolo y eficienciaSemilla 170020 · CPU sin GPU

Una prueba pequeña, trazable y barata

Aritmética de enteros 0–30: suma, resta y multiplicación. Una semilla de entrenamiento.

Antes de entrenar

  • 192 TRAIN / 32 DEV / 64 TEST.
  • Pares conmutativos sin cruzar particiones.
  • 32 TEST con plantilla vista y 32 con formulación nueva.
  • Selección y parada con DEV; checkpoints congelados antes de TEST.

Para gastar menos

  • Respuestas docente, códigos y embeddings fijos cacheados.
  • Scouts incluidos en los pasos; parada DEV evitó 2.700 actualizaciones.
  • Entrenamiento con 2 hilos; una tarea pesada a la vez.
  • Sin duplicar GGUF ni ejecutar entrenamientos para hacer este tablero.
Inferencia libre: recibe solo el prompt y los códigos que ella misma predice. La respuesta correcta solo etiqueta la pérdida.

Las ablaciones pagan la ingesta antes de vaciar o alterar el buffer. Son controles; desplegar memoria vacía podría omitir ese trabajo. BM25 combina componentes medidos en runs separados.
